## 能力 3：推导“发放率约等于截断 ReLU”与三种转换误差（第 7 章）

1. <b>（核心推导，来自第 7 章）</b> 从减法复位方程 $v[t] = v[t-1] + z[t] - \theta s[t]$ 出发，一步不跳对 $t=1..T$ 裂项求和，推出发放率精确等式 $r = \frac{1}{\theta}\big(\bar{z} - \frac{v[T]-v[0]}{T}\big)$；并说明为何恒定输入下取 $v[0] = \theta/2$ 能把最大量化误差从 $\theta/T$ 砍半为 $\theta/(2T)$。
2. <b>（误差归类与举例，来自第 7 章）</b> 请分别说出免训练转换中<b>截断误差、量化误差、到达不均匀误差</b>的成因，并回答：把 $T$ 拉到无穷大能消除哪一种、消不掉哪两种？
3. <b>（代码验证）</b> 在 <code>ch07_ann2snn_rate_and_errors.ipynb</code> 中，对比输入 <code>[+2, -2]</code> 与权重 <code>[0.6, 0.4]</code> 在 <code>T=5</code> 下的三种脉冲到达顺序（同步到达 / 正先负后 / 负先正后），解释为何三种顺序真实平均输入相同、输出发放率却分别是 <code>0.40 / 0.80 / 0.20</code>。

<toggle>
能力 3 参考答案（点击展开）

1. <b>第 1 题</b>：对 $v[t] - v[t-1] = z[t] - \theta s[t]$ 从 $t=1$ 加到 $T$，左边首尾相消得 $v[T]-v[0] = \sum_{t=1}^T z[t] - \theta\sum_{t=1}^T s[t]$；移项同除以 $\theta T$ 即得 $r = \frac{1}{\theta}\big(\bar{z} - \frac{v[T]-v[0]}{T}\big)$。当输入恒为 $z \in [0,\theta)$ 且 $v[0]=\theta/2$ 时，闭式总脉冲数为 $\lfloor \frac{zT + \theta/2}{\theta}\rfloor = \mathrm{round}(zT/\theta)$，向下取整变成四舍五入，误差对称落在 $[-\frac{\theta}{2T}, +\frac{\theta}{2T}]$ 内，最大误差砍半。
2. <b>第 2 题</b>：（a）<b>截断误差</b>：$\bar{z} > \theta$ 时每步最多发 1 脉冲导致上限卡在 $\theta$（拉大 $T$ <b>消不掉</b>）；（b）<b>量化误差</b>：$r$ 只能取 $1/T$ 整数倍（拉大 $T$ <b>可按 </b><b>$1/T$</b><b> 消除</b>）；（c）<b>到达不均匀误差</b>：前期正脉冲抢跑误发正脉冲而后期负脉冲无法撤回，或前期负脉冲压低膜电位导致后期正脉冲发不出（单极性 IF 下拉大 $T$ 也<b>无法保证自动消除</b>，需靠带符号负脉冲或差分编码纠偏）。
3. <b>第 3 题</b>：正先负后时前 3 拍先冲出冤枉正脉冲，后 2 拍负脉冲无法撤回（过冲到 <code>0.80</code>）；负先正后时前 2 拍把膜电位砸到深负区，吃掉了后面正脉冲的充电量（欠冲到 <code>0.20</code>）。
</toggle>

## 能力 4：线性穿透原理与 <code>max</code> / 乘法反例（第 1、7、9 章）

1. <b>（核心推导，来自第 1、7 章）</b> 写出多层网络第 $l$ 层在 $t=1..T$ 步对上游脉冲 $\theta^{(l-1)}\mathbf{s}^{(l-1)}[t]$ 加权求和并平均的等式，指出其中用到的线性性质；为什么偏置 $\mathbf{b}^{(l)}$ 必须每一步都加一次？
2. <b>（核心反例，来自第 7、9 章）</b>
   - 构造两个长度为 4 的二值脉冲序列，使得各自发放率均为 <code>0.5</code>，但逐拍取 <code>max</code> 后发放率变成 <code>1.0</code>（高估 100%）；
   - 同样用这两个序列，分别计算“逐步相乘再平均”与“各自平均再相乘”，展示二者为何不相等。
3. <b>（原理辨析，来自第 9 章）</b> <mention url="https://app.notion.com/p/41b0e3342e6f8189b3dcdf43ac9f4e6e">Inference-Scale Conversion（2025）</mention> \[[原文](https://arxiv.org/abs/2409.03368)\] \[[中文](https://app.notion.com/p/41c0e3342e6f81858a3fc2a999ed12b0)\] \[[代码](https://github.com/putshua/Inference-scale-ANN-SNN)\]（Bu 等，CVPR 2025）通过把 <code>MaxPool</code> 挪到神经元之前避开了脉冲 <code>max</code> 难题。为什么这个技巧套不到 <mention url="https://app.notion.com/p/41b0e3342e6f8167be5fc852220398d0">ViG 与 Pyramid ViG（2022）</mention> \[[原文](https://arxiv.org/abs/2206.00272)\] \[[中文](https://app.notion.com/p/41c0e3342e6f81c0b1c5eebb889ba8df)\] \[[代码](https://github.com/huawei-noah/Efficient-AI-Backbones/tree/master/vig_pytorch)\] 的 <code>max-relative</code> 聚合上？

<toggle>
能力 4 参考答案（点击展开）

1. <b>第 1 题</b>：$\frac{1}{T}\sum_{t=1}^T \big(W^{(l)}\theta^{(l-1)}\mathbf{s}^{(l-1)}[t] + \mathbf{b}^{(l)}\big) = W^{(l)}\big(\frac{\theta^{(l-1)}}{T}\sum_{t=1}^T \mathbf{s}^{(l-1)}[t]\big) + \mathbf{b}^{(l)} = W^{(l)}\boldsymbol{\varphi}^{(l-1)}(T) + \mathbf{b}^{(l)}$，核心依据是矩阵乘法的分配律（线性）。若 $\mathbf{b}^{(l)}$ 只在第 1 步加一次，时间平均后会被稀释成 $\mathbf{b}^{(l)}/T$。
2. <b>第 2 题</b>：取 <code>a = [1, 0, 1, 0]</code>、<code>b = [0, 1, 0, 1]</code>（均值均为 <code>0.5</code>）：
   - 逐拍 <code>max</code> 得 <code>[1, 1, 1, 1]</code>，平均为 <b><code>1.0</code></b><b> ≠ </b><b><code>max(0.5, 0.5) = 0.5</code></b>；
   - 逐拍相乘得 <code>[0, 0, 0, 0]</code>，平均为 <b><code>0.0</code></b><b> ≠ </b><b><code>0.5 × 0.5 = 0.25</code></b>（而若取同相 <code>a = b = [1, 0, 1, 0]</code>，逐拍相乘平均又变成 <b><code>0.5</code></b><b> ≠ </b><b><code>0.25</code></b>）。
3. <b>第 3 题</b>：Bu 等依赖 $\max_j \mathrm{ReLU}(z_j) = \mathrm{ReLU}(\max_j z_j)$ 把 <code>MaxPool</code> 挪到脉冲神经元前（且在 SNN 时域还隐含要求跨时间胜者不变）；而 ViG 的 <code>max-relative</code> 作用在<b>有符号相对特征差</b> $\tilde{\mathbf{x}}_j - \tilde{\mathbf{x}}_i$ 上，且结果直接拼接送进线性层，后面并没有紧跟一个 ReLU 可以交换位置。

## 能力 5：推导 $4\varepsilon$ 近邻不变定理（第 10 章）

1. <b>（核心推导，来自第 10 章）</b> 设所有节点的近似特征均满足 $\lVert \hat{\mathbf{x}}_u - \mathbf{x}_u \rVert_2 \le \varepsilon$。请用三角不等式严格证明：（a）任意两节点间欧氏距离扰动不超过 $2\varepsilon$；（b）若查询节点 $i$ 的第 $k$ 近与第 $k+1$ 近距离间隔 $\Delta d_k(i) = d_{(k+1)}(i) - d_{(k)}(i) > 4\varepsilon$，则近似后的 top-$k$ 邻居集合与原集合完全一致。
2. <b>（紧界构造，来自第 10 章例 10.1）</b> 已知查询点 $\mathbf{x}_0 = [0, 0]$、第 1 近 $\mathbf{x}_1 = [1, 0]$、第 2 近 $\mathbf{x}_2 = [0, 2]$、第 3 近 $\mathbf{x}_3 = [0, -2.5]$（$k=2$）。请算出临界误差 $\varepsilon_{\mathrm{crit}} = \Delta d_2(0) / 4$，并给出一组每个节点偏移不超过 <code>0.126</code> 却能让第 3 近反超第 2 近的具体扰动向量。
3. <b>（代码验证）</b> 在 <code>ch10_knn_stability.ipynb</code> 中运行 $N=49, C=32, k=9$ 模拟视觉图实验，验证为何所有满足 $\Delta d_9(i) > 4\varepsilon_{\mathrm{emp}}$ 的节点翻转率严格为 <code>0%</code>，并解释为何 $T=2$ 时普通半阈值 IF 翻转率飙升到 <code>50.57%</code>。

<toggle>
能力 5 参考答案（点击展开）

1. <b>第 1 题</b>：
   - （a）$\hat{\mathbf{x}}_i - \hat{\mathbf{x}}_j = (\mathbf{x}_i - \mathbf{x}_j) + (\hat{\mathbf{x}}_i - \mathbf{x}_i) - (\hat{\mathbf{x}}_j - \mathbf{x}_j)$，由正反三角不等式得 $|\hat{d}(i,j) - d(i,j)| \le \lVert \hat{\mathbf{x}}_i - \mathbf{x}_i \rVert_2 + \lVert \hat{\mathbf{x}}_j - \mathbf{x}_j \rVert_2 \le 2\varepsilon$。
   - （b）对任意原 top-$k$ 邻居 $a$（$d(i,a) \le d_{(k)}(i)$）与原非邻居 $b$（$d(i,b) \ge d_{(k+1)}(i)$），有 $\hat{d}(i,a) \le d_{(k)}(i) + 2\varepsilon < d_{(k+1)}(i) - 2\varepsilon \le \hat{d}(i,b)$，所有原邻居严格近于所有原非邻居，故 top-$k$ 集合不变。
2. <b>第 2 题</b>：$\Delta d_2(0) = 2.5 - 2.0 = 0.50 \implies \varepsilon_{\mathrm{crit}} = \mathbf{0.125}$。取 $\varepsilon = 0.126$：把 $\mathbf{x}_0$ 往下移 <code>[0, -0.126]</code>、$\mathbf{x}_2$ 往上移 <code>[0, +0.126]</code>、$\mathbf{x}_3$ 往上移 <code>[0, +0.126]</code>，新距离 $\hat{d}(0,2) = 2.252 > \hat{d}(0,3) = 2.248$，邻居立刻翻转！
3. <b>第 3 题</b>：$4\varepsilon$ 定理是严格充分条件故满足该条件的节点必然 0 翻转；$T=2$ 时半阈值 IF 每个通道只能取 <code>{0, 0.5, 1.0}</code> 三个离散值，大量节点坍缩到相同距离引发密集并列（ties），导致翻转率飙升。

能力 7 参考答案（点击展开）

1. <b>第 1 题</b>：
   - 距离矩阵：$D_{\mathrm{dist}} = \mathbf{q}\mathbf{1}_N^\top + \mathbf{1}_N\mathbf{q}^\top - 2XX^\top$（$q_i = \lVert \mathbf{x}_i \rVert_2^2$）。
   - （a）当节点 $i$ 在某通道上恰为局部最大值时，所有邻居 $\tilde{x}_{j,c} < \tilde{x}_{i,c}$，因此差值全为负，取 <code>max</code> 仍为负值，单极性脉冲无法表达。
   - （b）MobileViG 的 SVGA 写成 $\mathbf{x}_i - \mathbf{x}_j$（源码 <code>X - roll(X)</code>），与 ViG 的 $\tilde{\mathbf{x}}_j - \tilde{\mathbf{x}}_i$ 方向恰好相反。
2. <b>第 2 题</b>：
   - 更新方程：$I^l[t] = m_r^l[t] + x^{l-1}[t]$（式 20/94），$m_r^l[t+1] = m_r^l[t] + \frac{x^{l-1}[t] - x^l[t]}{t}$（式 21/95），$m^l[t] = v^l[t-1] + I^l[t]$（式 96），$v^l[t] = m^l[t] - x^l[t]$（式 99）。
   - （a）由数学归纳法可证 $v^l[t-1] = (t-1)\,m_r^l[t] + v^l[0]$，缺失的 $(t-1)$ 倍一直存在普通膜电位 $v^l[t-1]$ 里，与式 (20) 的 $1\cdot m_r^l[t]$ 相加恰好凑出 $t\,m_r^l[t]$！
   - （b）正文式 (19) 把附录 D 证明式 (48) 中的 $m^l[t-1]$ 误印成了 $m^l[t]$ 却保留了首项的加号；正确写法是用 $m^l[t-1]$ 配加号（或用 $m^l[t]$ 配减号 $-\frac{x_A^{l-1}[t]\cdot x_B^{l-1}[t]}{t}$）。
3. <b>第 3 题</b>：DCGS 虽然靠多阈值差分在极低 $T=4$ 下大幅压低特征误差、抑制了 $k$-NN 翻转，但它对 <code>max-relative</code> 和动态距离排序仍退回非脉冲浮点分级单元；且在静态图上仍面临 INT4/INT8 量化 GNN 的强能耗竞争，必须与流式时间差分稀疏性结合才能真正闭环。
